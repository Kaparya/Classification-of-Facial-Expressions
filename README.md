# Классификация выражений лиц с детектированием эмоций в речи

## Выпускная квалификационная работа (ВКР)

### 🎯 Цель проекта
Разработка системы для классификации человеческих эмоций в режиме реального времени на основе мультимодального анализа (видеопоток с веб-камеры и аудиопоток с микрофона).

### 🚀 Основные задачи
1.  **Детектирование речевой активности (VAD)**: Точное определение моментов, когда человек начинает и заканчивает говорить, чтобы анализировать только информативные отрезки.
2.  **Бинарная классификация экспрессии**: Определение, является ли текущее состояние человека "нейтральным" или "эмоционально окрашенным".
3.  **Детальная классификация эмоций**: Распознавание конкретных эмоций (Счастье, Гнев, Грусть, Удивление и др.) для эмоционально значимых фрагментов.
4.  **Мультимодальная интеграция**: Синхронизация данных аудио и видео для повышения точности и устойчивости системы к шумам.

---

### 🛠 Текущий этап разработки: Анализ и обучение VAD моделей
На данный момент фокус сосредоточен на первой критически важной задаче — **Voice Activity Detection (VAD)**. Для обеспечения максимальной точности и производительности проводится сравнительный анализ четырех подходов:

1.  **MLP (Multi-Layer Perceptron)**: Базовая нейросеть для быстрой покадровой классификации спектральных признаков (MFCC).
2.  **LSTM (Long Short-Term Memory)**: Рекуррентная сеть, способная учитывать временной контекст и "память" звуковой дорожки.
3.  **1D-CNN (Convolutional Neural Network)**: Сверточная сеть для поиска специфических частотных паттернов в голосе.
4.  **MediaPipe Tasks (Visual VAD)**: Визуальное детектирование речи по движению губ (landmarks) для фильтрации фоновых голосов.

**Датасет для обучения**: RAVDESS (The Ryerson Audio-Visual Database of Emotional Speech and Song).

### 💻 Технологический стек
*   **Язык**: Python 3.10+
*   **Глубокое обучение**: PyTorch (с поддержкой ускорения Apple MPS для чипов M1/M2/M3)
*   **Компьютерное зрение**: MediaPipe Tasks, OpenCV
*   **Обработка звука**: Librosa, SoundDevice, Silero VAD
*   **Классификация эмоций**: HSEmotion (библиотека А.В. Савченко)
*   **Среда**: Jupyter Notebook (`.ipynb`) для исследований и модульные скрипты (`.py`) для продакшн-пайплайна.
